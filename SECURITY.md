# Security Policy

## 🔒 Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.1.x   | :white_check_mark: |
| < 3.0.0 | :x:                |

## 🛡️ Reporting a Vulnerability

TurboGPT operates 100% locally in your browser with zero telemetry or remote analytics.

If you discover a potential security issue or data leakage vulnerability:
1. Please open an issue on GitHub or submit a Pull Request with a proposed fix.
2. We take security and privacy with the utmost seriousness and will address verified vulnerabilities promptly.
