# Contributing to TurboGPT

Thank you for your interest in contributing to TurboGPT! We welcome contributions from developers, designers, and enthusiasts worldwide.

---

## 🛠️ How to Contribute

1. **Fork the Repository** to your own GitHub account.
2. **Clone your fork locally**:
   ```bash
   git clone https://github.com/your-username/turbogpt.git
   ```
3. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b feature/amazing-feature
   ```
4. **Make your changes** and test them by loading unpacked in Chrome at `chrome://extensions`.
5. **Commit your changes**:
   ```bash
   git commit -m "feat: add amazing feature"
   ```
6. **Push to your fork**:
   ```bash
   git push origin feature/amazing-feature
   ```
7. **Open a Pull Request** with a clear explanation of your changes.

---

## 📜 Code of Conduct & Principles
- Keep the extension 100% private, local-only, and free of any telemetry.
- Respect all users and maintain clean, readable code.
